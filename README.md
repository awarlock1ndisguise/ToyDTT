# ToyDTT Project.
---
## What is this project about?
This is a toy Discrete Trial Training project, that with the help of some pre-made files from Intelligent-Robotics-Lab (the DTTAgent method signatures (src/dtt_agent/agent.py), the child-answer input schema and the response envelope (src/dtt_agent/contracts.py), a working CLI runner ,six input-only and
public contract tests (tests/test_public_contract.py)), I had to reaserch and make my own Python DTT agent.

## My DTT Agent.

The only lesson my agent teaches is shape recognition. One session has 3 iteams (Circle, Square and Triangle), and every data that walks you though the targets is tsored in **config.py**
